# Bugs and incidents

## Report a bug

1. Open **Bugs** and click **Report bug**. Search for an existing report before creating another. If the form finds a match, inspect it before proceeding.
2. Add a **Title**, **Steps to reproduce**, and a **Priority**. Describe expected and actual behavior and include screenshots if useful. Choose the project's location, or check **Not sure where it belongs — send to triage**.
3. Click **Report bug**. A placed report is committed directly; an unplaced report goes to **Candidates** so a triager can place and commit it or decline it. If a similar report already covers the problem, follow that report instead of submitting another. Use **Bugs** to track triage and SLA information. Priority sets the SLA; severity describes the impact.

## Report an incident

1. On **Board**, click **Report incident**. Enter a **Title** and **Impact** (who or what is affected, how, and since when), choose **Severity** and the location, then click **Report incident**.
2. The incident is committed and starts in progress. The reporter becomes Incident Lead. Use the issue to track **Impact started**, **Detected**, **Mitigated**, and **Resolved** as the situation changes.
3. Open **Incidents** to browse ongoing and resolved incidents, mitigation and resolution times, and follow-up progress. Use the [severity guide](../severity.md) when classifying impact and the [postmortem guide](../postmortem.md) for the follow-up.

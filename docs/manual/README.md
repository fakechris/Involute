# Involute user manual

Use this manual to plan work, follow delivery, and review what people and agents finish. Start with the web app; the agent and operator references are linked where you need them.

1. [Getting started](getting-started.md) — sign in and create your first issue.
2. [Workspace and navigation](workspace-and-navigation.md) — switch teams and find the right screen.
3. [Work items](work-items.md) — create, edit, peek, and connect issues.
4. [Views and search](views-and-search.md) — use Board, Backlog, Search, IQL, and saved views.
5. [Candidates and committing](candidates.md) — decide which proposals to take on.
6. [In Review and closing work](review.md) — accept, return, or close superseded work.
7. [Needs you and Activity](needs-you-and-activity.md) — separate decisions from notifications.
8. [Projects, milestones, and delivery](projects-and-delivery.md) — plan and inspect delivery over time.
9. [Bugs and incidents](bugs-and-incidents.md) — report defects and track live impact.
10. [Working with agents](agents.md) — connect over MCP and review runs and evidence.
11. [Settings, teams, and integrations](settings.md) — manage access and connect GitHub.
12. [Troubleshooting](troubleshooting.md) — diagnose common issues and know when to escalate.

Button names are shown as they appear in the English web app. Some controls depend on your role, selected team, or server configuration. Paths such as `/backlog` are relative to your Involute server.

Reviewers walking an acceptance pass: [acceptance scenarios](../acceptance-scenarios.md) lists the recurring checks and the tests that hold them.

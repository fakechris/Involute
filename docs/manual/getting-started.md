# Getting started

1. Open your organization's Involute URL and sign in with Google using the invited account or one on an approved domain. If sign-in is refused, ask a workspace admin to check your access; having a Google account alone is not enough. See [who can sign in](../permissions.md#1-who-can-sign-in).
2. Select your team in the sidebar, then open **Board**. It shows committed work, not undecided proposals. If you don't see an expected team or project, ask its owner to check your access before creating a duplicate.
3. Open **Projects** and find the project where your work belongs. If there isn't one, use **New project** if you have access, or ask the team to create it.
4. Press `C` outside a text field. In **Create issue**, enter a **Title**, add a **Description**, and choose the **Project** and **Location**. For a general task, **No milestone** places it directly under the selected project. Click **Create issue**.
5. Find the new issue on **Board** or **Backlog**. Copy its identifier from the issue if you need to refer to it in a comment or find it through **Search** later.

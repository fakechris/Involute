# In Review and closing work

## Accept or return submitted work

An agent finishing a run is not the same as the team accepting the outcome. Open **In Review** (`/in-review`) and choose **Open context** on an item. Compare **Acceptance** and the contract with the run and evidence; check the actual artifact or change, not just the completion message.

- Click **Accept** when the result meets the contract. This completes the work and records the decision.
- Click **Return** when it needs another attempt. Record what still needs to change on the work so the next person or run can act on it. If the card offers **Review delivery package** instead, use that path to inspect the package and decide there.
- To review multiple eligible items together, select their checkboxes, optionally enter a note in **Reason (optional decision note)**, then choose **Bulk accept** or **Bulk reject / return**. Check for failed items; the decision is recorded per work item.

See [evidence gap hints](agents.md#read-evidence-gap-hints); hints are not an acceptance decision.

## Close work that has a replacement

On Board or Backlog, choose **Superseded, open** to find unfinished work that has a replacement. Check that each replacement really covers the old work. Select the items and move them to the team's Canceled state. Confirm the shown resolution and reason for each item; where there is no replacement, supply the required shared values. A missing value, live claim, or conflict can leave an item open. Read the result, and use the status undo action if you moved the wrong items; successful writes from the batch form one undo action.

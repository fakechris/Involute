# Workspace and navigation

Team selection sets the working context for surfaces such as Board and Delivery latency. Expand a team in the sidebar for team-specific destinations. Use the project selector on Board or Backlog to narrow the selected team's work; clearing the project is not the same as switching teams.

| If you want to… | Open |
| --- | --- |
| Move active committed work through its states | **Board** (`/`) |
| Scan and sort committed work in a table | **Backlog** (`/backlog`) |
| Decide which proposals to take on | **Candidates** (`/candidates`) |
| Validate submitted work | **In Review** (`/in-review`) |
| Deal with decisions waiting on you | **Needs you** (`/todo`) |
| Catch up on notifications | **Activity** (`/inbox`) |
| Find your assignments | **My Issues** (`/my-issues`) |
| Find work across the areas you can access | **Search** (`/search`) |
| Reopen a saved Board or Backlog configuration | **Views** (`/views`) |
| Browse project structure, timelines, or metrics | **Projects**, **Milestones**, **Graph**, or **Delivery latency** |

The sidebar **Search** button opens the command palette. Use `Ctrl+K` (`⌘K` on macOS) to open the same palette from the keyboard. Press `?` outside an input for the in-app shortcut list. For filtering rather than just jumping to an issue, see [views and search](views-and-search.md).
